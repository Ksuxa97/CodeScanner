# 📱 CodeScanner

Мобильное iOS-приложение для **сканирования штрих-кодов и QR-кодов**, получения информации о продуктах через [Open Food Facts API](https://world.openfoodfacts.org/), сохранения данных локально и удобного просмотра истории сканирования.

## 🧭 Основной функционал

- 📷 Сканирование штрих-кодов и QR-кодов с помощью `AVFoundation`  
- 🔦 Включение/выключение фонарика прямо на экране сканера  
- 🔐 Проверка и запрос разрешений на доступ к камере, обработка ошибок  
- 🌐 Получение информации о продукте по штрих-коду (название, бренд, ингредиенты, Nutri-Score) через Open Food Facts API  
- 📝 Отображение содержимого QR-кода с возможностью открыть ссылку  
- 💾 Сохранение всех отсканированных кодов в локальную базу (`Core Data`) без дублирования  
- 🧾 Список отсканированных кодов с датой, названием и типом кода  
- 🪪 Экран деталей кода с возможностью редактирования названия и **поделиться** информацией

## 🧱 Архитектура проекта

### Паттерн проектирования
Приложение использует **MVVM (Model-View-ViewModel)** в сочетании с **координатором** для навигации.

- **SwiftUI** - UI фреймворк
- **Core Data** - локальное хранилище
- **AVFoundation** - работа с камерой и сканирование кодов
- **URLSession** - сетевые запросы
- **Combine** - реактивное программирование
- **Swift Concurrency (async/await)** - асинхронные операции
- **Open Food Facts API** - информация о продукте по штрих-коду
- **MVVM + Coordinator** - архитектурные паттерны

### Основные компоненты

#### 1. **Models**
- `ScannedCodeModel` - основная модель данных для сканированных кодов
- `CodeType` - enum для определения типа кода (QR/штрихкод)
- `Product` - модель данных продукта из Open Food Facts API

#### 2. **View Models**
- `ScannerViewModel` - управление логикой сканирования, обработка результатов
- `ScanListViewModel` - управление списком истории сканирований
- `ScanDetailViewModel` - управление детальной информацией о сканировании

#### 3. **Views**
- `ScannerView` - экран сканирования с камерой
- `ScanListView` - список истории сканирований
- `ScanDetailView` - детальная информация о сканировании
- `MainView` - корневой view с навигацией

#### 4. **Services**
- `CameraService` - управление камерой и захватом видео
- `OpenFoodFactsService` - API клиент для получения информации о продуктах
- `StorageManager` - менеджер для работы с Core Data

#### 5. **Coordination**
- `Coordinator` - управление навигацией между экранами
- `Route` - enum с определением всех возможных маршрутов

### Поток данных
1. **Сканирование** → `CameraService` обнаруживает код → `ScannerViewModel` обрабатывает
2. **Сохранение** → `StorageManager` сохраняет в Core Data
3. **Отображение** → View Models предоставляют данные Views
4. **Навигация** → Coordinator управляет переходами между экранами

## 📲 Руководство по использованию

1. 📱 **Запустите приложение** на устройстве или симуляторе.  
2. Нажмите "+" на главном экране
3. 📸 Разрешите доступ к камере при первом запуске.  
4. Наведите камеру на штрих-код или QR-код.  
5. После успешного сканирования:  
   - для штрих-кода — информация о продукте будет получена автоматически;  
   - для QR-кода — будет отображено содержимое.  
6. Отсканированные коды сохраняются в локальное хранилище.  
7. Откройте список кодов на главном экране, чтобы:  
   - просмотреть сохранённые данные,  
   - нажать на запись для просмотра деталей
   - удалить запись свайпом влево
8. Откройте детальный просмотр записи, чтобы
   - изменить локальное название
   - поделиться информацией о сканировании
   - открыть ссылку для QR-кодов с URL

## 📝 Примечания

- Для работы сканирования штрихкодов требуется интернет-соединение (для получения данных о продуктах)
- История сохраняется только локально на устройстве
- Поддерживается iOS 16.6 и выше
